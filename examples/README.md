# Fennel examples

Run either script from the repository root, or run `./run.sh` from an example
directory:

```sh
./examples/basic/run.sh
./examples/profiles/run.sh
```

- `basic` wires two components with a reference and runs their lifecycle.
- `profiles` selects configuration by profile and binds a runtime value.

For larger applications and feature-specific examples, see the
[Lua Stitch examples](https://github.com/winterstream/lua-stitch/tree/main/examples).
Those examples use the Lua port's API and syntax.
